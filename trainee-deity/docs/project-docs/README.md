## 二、一句话认识这个项目

> 一款**纯静态浏览器城市建造 / 神明养成游戏**：玩家扮演见习神明，用神力改造地形、
> 划定居所/农田/工业/信仰四类区域，子民自动建造并繁衍；人口与产能达标后可建造**世界奇迹**
> 并**推进时代**（共五个时代）。**零运行时依赖、零后端、离线可玩**。

| 项 | 值 |
|---|---|
| 类型 | 网页城市建造 + 神明养成（**无战斗**） |
| 技术栈 | 原生 ES Module + Three.js r161（本地 vendor）+ **无打包器** |
| 生产代码 | 14 个模块 / 约 **7,300 行** |
| 测试 | 17 个自动化测试（Node）+ 7 个浏览器测试 |
| 运行方式 | 任意静态服务器托管，`index.html` 直接可跑 |
| 存档 | 浏览器 `localStorage`（3 槽 + 快速档 + JSON 导入导出） |

## 五、重要事实与风险摘要

在深入细节前，先给你**四条最需要注意的**：

### 5.1 这是一个"零后端"游戏

【已实现】实测 `js/` 内**零网络调用、零统计 SDK、零账号后端**：
账号与存档全部在浏览器 `localStorage`。这意味着：
- 换设备 / 清缓存 = 进度丢失（有 JSON 导出导入可手动迁移）
- **无任何遥测**：线上无法知道玩家在哪一步流失 【待确认：是否属有意设计】

### 5.2 密码哈希依赖 HTTPS

【已实现】`js/auth.js` 主算法为 **PBKDF2-SHA256**，但依赖 `crypto.subtle`，
而该 API **仅在安全上下文（HTTPS 或 localhost）可用**。
纯 HTTP 部署会**降级为 FNV-1a 弱哈希**（有 console 告警、且如实标注不冒充强哈希）。
**故 HTTPS 不是可选项，而是安全前提。**

### 5.3 时代链曾"物理不可达"

【已实现·已修复】岛屿可建造格实测仅 **4,979~5,881/种子**，叠加「8 邻域空置」规则后
建筑地块**硬上限 ≈1,350**。而 E4/E5 的原始需求达 6,500 / 19,500 格 → **时代链无法通关**。
2026-10 引入**建筑代理比 `BUILD_Q`**（1 格 = N 栋）后解决，关键路径降至 1,060~1,185 格。
详见 `08_时代进阶与里程碑.md` 与 `09_数值与公式手册.md` §9。

### 5.4 零冗余的星星预算

【已实现】每时代恰好 3 个里程碑，而 `starCost = 3` —— **零冗余**。
任一里程碑不可达（例如奇迹里程碑指向了本时代无法建造的奇迹）即**时代硬锁死**。
这是本项目历史上最贵的一次回归，规格文档 `numeric-design.md:16-19` 专门记录。
详见 `08_时代进阶与里程碑.md`。
