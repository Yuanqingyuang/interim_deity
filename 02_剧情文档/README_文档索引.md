## 已固定的剧情原则

- 玩家就是神明；不为玩家写独立角色台词或内心独白。
- 开场有神界与神位交接动画，由前辈神明快速介绍任务。
- 村民最初不知道神明存在；玩家回应祈愿、降下第一场雨后，村民才开始相信神明。
- NPC 直接向玩家交谈，使用尊称、敬语与请求语气。
- 档案馆同时包含官方史籍与普通居民的日记、书信、手记等私人记录。
- 日常剧情低打扰，主动阅读时内容完整；隐藏线索不作为通关门槛。
- 五时代核心始终是文明建造与神明见习；文明结局和神位评定分别呈现。
