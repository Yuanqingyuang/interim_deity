# 实习神明 · 项目现状总览

> 与当前 Web 原型同步（无边界区块 + 账号存档日志 + 公式化数值）。

## 1. 一句话

网页端「实习神明」：种子地形 + 分区自动建造 + 五大时代；本地多用户存档与压缩日志。

## 2. 架构

```
index.html (登录/菜单/HUD)
    ↓
js/main.js     主循环 · 自动建造 · 暂停 · 存档接线
js/state.js    G.chunks Map（10×10 区块）· 序列化
js/terrain.js  heightAt/riverMask/sampleHeight · 工具 · 选址
js/render.js   Three 地形/建筑/村民 · 昼夜光照/阴影/云/水 · OrbitControls
js/formulas.js T(E) · 人口/粮/产能 · LAYOUT
js/auth.js     本地用户 + 密码哈希
js/saves.js    slot1/2/3 + quick · 写档失败返回 null
js/log.js      代号编码 → 中文展开
```

## 3. 世界与地形

- **区块**：`CHUNK=10`，开局 `START_CHUNKS=4`
- **扩展**：有建筑的区块 `ensureChunkRing` 补 8 邻域
- **高度**：域扭曲 → 大陆度 → ridged 山脉 + 丘陵
- **河流**：`riverMask` 冲刷河床
- **工具**：抬升 / 下沉 / **平整**（局部均值 + 羽化）/ 引水 / 绿化

## 4. 建筑与自动建造

| 类型 | 规则摘要 |
|------|----------|
| 居住 | 粮、产能有余且住房缺口时优先 |
| 农田 | 粮不够时建；田–田可密铺 |
| 工业 | `D_res≥6`、1×2 批次、区块容量 |
| 教堂 | 跟随公式 low |

- 手工：单击 1 格，拖动连续
- 选址：围绕居住质心随机采样

## 5. 渲染与光照

- **昼夜**：`G.dayTime` 0→1 循环，`SUN_KEYS` 关键帧（`sampleSun`）插值出太阳/半球光/环境光强度与色调、雾色、水色
- **太阳**：方向光绕**城区中心**（`_focus`）半径 55 环绕，`elev` 有下限（太阳不下山）
- **阴影**：`PCFShadowMap`，1024²（正交框半径 >70 时自动升为 2048² 抑制锯齿）；正交框半径随区块范围自适应（`_syncShadow`，步进 0.5 才重建），地形 / 建筑 / 树 / 奇观 / 村民全部投影，水面接收阴影
- **阴影相机 far/near 必须随正交框半径 R 派生**（2026-10 修复）：太阳距焦点 ≤ 约 74，正交框远端再延伸 R，故 `far` 取 `74+R+12`、`near` 取 `max(0.5, 74-R-12)`。此前硬编码 `far=170`，R=120 时正午需要约 194 → **大城外围阴影被裁**
- **天空**：512×256 canvas 竖向渐变 + 夜间星点 → `scene.background`，每 0.5s 重建
- **云层**：单个 220×220 平面 + 平铺云斑纹理；用 `MeshBasicMaterial`，**必须手动按昼夜着色**（Basic 材质不吃光照，否则夜里云是纯白）；位置跟随 `_focus`（城区焦点），否则城市远离原点时云会飘走
- **时代配色**：`PALETTES[era]` 控制地表 / 水 / 天空 / 雾

> ⚠️ 改 `sun.shadow.camera` 的 `left/right/top/bottom` 之后**必须**调 `updateProjectionMatrix()`，否则生效值仍是默认 `±5`（阴影只覆盖 10×10 世界单位）。

## 7. 账号 / 存档 / 日志

- 登录：昵称 + 密码，`localStorage`。KDF 三态（见 `js/auth.js` 的 `kdf` 标签）：
  - **PBKDF2-SHA256**（主用）—— 安全上下文（`crypto.subtle` 可用，即 HTTPS 或 localhost）下的默认算法
  - **sha256** —— 旧档兼容标签；早期版本在非安全上下文以此标签写入的其实是 FNV 值，故读取时代码会按上下文分别处理
  - **FNV-1a-weak** —— 非安全上下文的弱兜底，**如实标注、绝不冒充强哈希**，并在 console 明确告警。仅适用于本机娱乐场景
- 存档：3 槽 + 快速档 + JSON 导出/导入
- 自动存档：每 180s 写快速档；`writeSave` **失败返回 `null`**（配额/序列化），调用方必须检查并提示玩家
- 日志：`[code,t,x,y]` 压缩
- 暂停：冻结 tick 与 `G.time`

## 10. 已知约束

- 存档仅本机（localStorage）；配额耗尽/序列化失败时写入返回 `null`，会提示玩家手动保存
- 无限图为点采样，非全图 D8 水文
- 大地图需避免全图扫描：`screenToTile` 已按**射线**记忆化（同格内移动不再重复 raycast，
  相机移动会改变射线从而自动失效）；`residentialStats` / `collectZoneXY` / `findAutoSite`
  仍为全图扫描，属已知待优化项
- 阴影正交框半径上限 120；`far/near` 已随 R 派生，故 R=120 时外围仍有阴影。
  超出 120 的城区外圈仍无阴影（上限本身是性能取舍）
- 天空 / 云 / 地形贴图均为程序生成，无美术资源；音频为 Web Audio 振荡器实时合成（放置 / 奇迹完工 / 时代进阶三类事件，无外部音频资产）
