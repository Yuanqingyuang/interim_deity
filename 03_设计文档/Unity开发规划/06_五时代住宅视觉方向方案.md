# 06 · 五时代住宅视觉方向方案

> 第一阶段交付物 6/9（任务书 §八-6）。配套：`05_Blender建模与美术规范.md`。
> 目标：让五个时代在**同一视角**下具备**可辨识的进化关系**，而**不是"同一栋房子换颜色"**。
> 依据：现有 `02_剧情文档`（时代主题/奇迹）、`js/config.js`（`PALETTES` 地貌配色、`BUILDING_STYLE` 建筑配色与形体语义）、`numeric-design.md`（`BUILD_Q` 体量约束）。
> ⚠️ 本方案是**视觉提案 + 可执行规格**，不是已完成模型（本沙箱无 Blender）。

### 0.2 来自玩法的硬约束

| 约束 | 影响 |
|---|---|
| 1 格 = 1 建筑，主体占地 ≤1.0×1.0 | 所有时代都必须"装进一格"；差异靠**轮廓/屋顶/比例/材质**，不靠占地 |
| 8 邻域空置（密度 ≤25%） | 建筑之间有间距 → **轮廓可被完整看到**，剪影设计价值极高 |
| `BUILD_Q`：E3=3 / E4=6 / E5=20 | **E3 起必须能表现"1 格 = 多栋"**：主楼 + 2–3 个缩小副楼（副楼复用主楼 Mesh） |
| 俯视/斜俯视为主 | **屋顶形式是最强的时代识别位**；底面可省略 |

## 1. 五时代进化关系矩阵（核心产出）

> 读法：每一行是一条**进化轴**，从左到右看该轴如何随时代演进。**任何两个相邻时代至少要在这 4 条轴中的 2 条上明显不同**（否则会出现"换漆感"）。

| 进化轴 | E1 蛮荒 | E2 城邦 | E3 封建 | E4 工业 | E5 星际 |
|---|---|---|---|---|---|
| **① 轮廓（剪影）** | 低矮**穹丘/圆锥**，单峰 | **方正**单体，有柱廊横向展开 | **高窄**、竖向主导，带扶壁凸起 | **长条多跨**，锯齿齿列 + 竖向烟囱 | **堆叠方块**，圆角与悬浮环带 |
| **② 屋顶形式** | 圆锥 / 圆穹 | **人字坡（山墙）** | **陡尖顶**（高坡度） | **锯齿采光顶 + 平顶裙房** | **半球穹顶 + 环带** |
| **③ 结构材料** | 木骨 + 茅草 + 毛石基 | **砌石**（方整石） + 木梁 | 石基 + **木框架（半木/悬挑）** + 瓦 | **砖 + 混凝土 + 金属（铆接钢）** | **轻质复合板 + 发光带**（无砌体感） |
| **④ 开窗方式** | **无窗**，仅门洞（洞口不规则） | 少量**方窗**，门廊有**柱列** | **拱窗/尖拱窗**，窗小而密，带**发光内窗** | **大面积工业玻璃**（带状/锯齿采光） | **无缝发光面**（窗与墙同化，光条嵌入） |
| **⑤ 体量比例（宽:高）** | 约 **1.2 : 0.9**（宽扁） | 约 **1.0 : 1.2**（正方偏稳） | 约 **0.85 : 1.4**（窄高） | 约 **1.0 : 2.2**（长条但高） | 约 **0.9 : 1.7** + 副楼群（不定形） |
| **⑥ 秩序感** | 有机、随机（自然聚落） | **对称**、轴向（古典秩序） | 竖向强调、装饰密集 | **功能主义**、重复模数 | **模块化**、无装饰 |

**一句话概括进化**：**从"自然长出来的圆"→"人为的正"→"向天空的尖"→"为机器服务的长"→"为人之外的模块"。**

## 2. 色彩方案（在现有调色板内取值，不另造体系）

| 时代 | 建筑主体色（`BUILDING_STYLE.wall`） | 屋顶色 | 点缀/发光 | 与地貌的关系 |
|---|---|---|---|---|
| E1 蛮荒 | `0xd58b42`（土黄木色） | `0xe5aa56`（茅草） | 装饰 `0xd49e4a` | 与草绿 `0x6bd032` 形成**暖冷对照**，靠草顶融入自然 |
| E2 城邦 | `0xe38b4a`（暖石） | `0xf4ad63`（浅陶瓦） | 侧墙 `0xb1652d` | 与沙岸 `0xfcd88f` 同族，显得"就地取材" |
| E3 封建 | `0xd1cab9`（灰白灰泥） | **`0xcb411e`（红瓦，强对比）** | 发光窗 `0xffe48c` | 红顶在深绿 `0x6dcc35` 上**极醒目**，是 E3 的第一识别色 |
| E4 工业 | `0x9da8ba`（冷灰） | `0x55616e`（深板岩） | 窗 `0xffe08c`（暖黄） | 冷灰在暖调地表上"突兀"，符合工业化对自然的侵入感 |
| E5 星际 | `0x6ad1ec`（浅青） | `0xf2fbff`（亮白） | 发光 `0x40a8cc` | 与偏青地表 `0x62dba4` + 岩 `0x8b92ad` 统一为**高冷未来感** |

> ⚠️ **配色沿用用户既有决定**："配色先保留，等待后续测试是否合适"。本表**不改动** Web 的调色板值，只用于 Blender 建模时的材质取色参考。若未来调整，需同步 Web 与 Unity 两侧。

## 3. 各时代基础住宅（Variant A）

### E1 蛮荒 · 基础住宅 A：圆形茅草棚

| 维度 | 规格 |
|---|---|
| 外形 | 圆筒木骨墙 + **圆锥茅草顶**，顶略大于墙（出檐） |
| 轮廓 | 低矮单峰，宽扁 |
| 材料 | 木骨（细柱，8–10 根）+ 茅草（浅黄，轻微不规则）+ 毛石基座 |
| 开窗 | **无窗**；一个不规则门洞，无门扇（挂草帘） |
| 屋顶 | 圆锥，坡度约 45°，**锥尖有小束草结** |
| 体量 | 宽 ≈1.0，高 ≈0.9；檐口高度 ≈0.5 |
| 识别要点 | 唯一使用**曲顶**的时代，剪影最"软" |

### E2 城邦 · 基础住宅 A：方形砌石屋 + 柱廊

| 维度 | 规格 |
|---|---|
| 外形 | 方正石砌单体 + **人字坡（山墙）屋顶** + 正面 **2–3 根短柱的门廊** |
| 轮廓 | 横向展开的稳定矩形，柱廊产生**节奏性竖向线条** |
| 材料 | 方整砌石（暖石色）+ 木梁 + 浅陶瓦屋面 |
| 开窗 | 少量**方窗**（1–2 个，小），门廊为柱列 |
| 屋顶 | 人字坡，坡度约 30°，**山墙面朝正门方向** |
| 体量 | 宽 ≈1.0，高 ≈1.2 |
| 识别要点 | **对称 + 柱列**是古典秩序的标志；与 E1 的"圆"形成第一次强反差 |

### E3 封建 · 基础住宅 A：陡尖顶木石屋 + 扶壁

| 维度 | 规格 |
|---|---|
| 外形 | 窄高石基 + 上层木框架，**陡尖顶**，**角部/侧墙有扶壁凸起** |
| 轮廓 | **竖向主导**，屋脊高耸，扶壁制造竖向节奏 |
| 材料 | 灰白灰泥墙 + 外露木框架 + **红瓦陡顶** |
| 开窗 | **尖拱/拱形小窗**，窗内**发光**（`0xffe48c`） |
| 屋顶 | 陡尖（坡度约 55–60°），屋脊可能有小尖饰 |
| 体量 | 宽 ≈0.85，高 ≈1.4（本时代最高） |
| 识别要点 | **红顶 + 陡坡 + 竖向扶壁**三者叠加；发光小窗是 E3 独有 |

### E4 工业 · 基础住宅 A：长条排屋 + 锯齿顶 + 烟囱

| 维度 | 规格 |
|---|---|
| 外形 | **长条多跨**排屋（沿一格内做 3–4 个重复开间），**锯齿采光顶**，一端**砖砌烟囱** |
| 轮廓 | 水平长条 + 顶部**锯齿齿列** + 竖向烟囱 |
| 材料 | **砖（`0x7a5c4e` 系）** + 混凝土灰 + 铆接金属构件 |
| 开窗 | **大面积工业玻璃**（带状，纵向连续），暖黄内光 |
| 屋顶 | 锯齿（朝北采光）+ 局部平顶 |
| 体量 | 宽 ≈1.0，高 ≈2.2（**明显更高**） |
| 识别要点 | **锯齿轮廓**是工业时代的招牌；与 E3 的"尖"不同——E4 是**机械重复**而非装饰性尖顶 |

### E5 星际 · 基础住宅 A：穹顶模块单元

| 维度 | 规格 |
|---|---|
| 外形 | 圆角方块或圆筒基座 + **半球穹顶**，**发光环带**环绕，**多体聚落（主楼 + 2–3 副楼）** |
| 轮廓 | 圆润几何 + 悬浮环，副楼群使整体**边界不定形** |
| 材料 | 轻质复合板（浅青 + 亮白），**无砌体/木构感**；接缝为光带 |
| 开窗 | **无明显窗**——发光面与墙同化，光条嵌入结构中 |
| 屋顶 | 半球穹顶 + 环带 |
| 体量 | 宽 ≈0.9，高 ≈1.7；因 `BUILD_Q = 20`，**必须成群出现** |
| 识别要点 | **唯一有"悬浮环带"与发光同化面的时代**；副楼群是 E5 独有的"城中之城"观感 |

## 4. 各时代住宅变体（Variant B）——必须有真实形态差异

> 规则（任务书 §4.3）：**变体应是形态差异，而非仅改色/材质/缩放。** 下表每一项都在**体量或结构**上与 Variant A 不同。

| 时代 | Variant B 方案 | 与 A 的**结构性**差异（可验证） |
|---|---|---|
| E1 蛮荒 | **低矮长屋**（双坡茅顶，多开门洞） | 主体从 `cyl` 改 `box`（**长宽比 ≥1.6 : 1**）；屋顶从**圆锥**改**双坡**；高度更低（≈0.7）；门洞从 1 个增为 2–3 个 |
| E2 城邦 | **两层窄高石屋 + 抬高基座（阶梯）** | 从**单层**改**两层**（高 ≈1.6，宽 ≈0.8）；基座加**2–3 级台阶**；屋顶从人字坡改**平顶带女儿墙**（消除山墙）；无柱廊改**二层小阳台** |
| E3 封建 | **半木悬挑屋（上层外挑）** | 上层楼板**向外悬挑**（jettied，外挑 ≈0.12，仍在硬上限内）；屋顶从**陡尖**改**双坡中坡（约 40°）**；立面从灰泥改为**密集木框架（可见格构）** |
| E4 工业 | **多层公寓 + 外部铁楼梯/外廊** | 从**横向长条**改为**竖向多层**（高 ≈2.2，宽 ≈0.8）；烟囱从"砖砌粗筒"改**细金属排气管组**；屋顶从锯齿改**平顶 + 水箱**；增加**外部铁楼梯** |
| E5 星际 | **垂直堆叠舱体塔 + 悬浮环** | 从**单穹顶**改**竖向堆叠 3–4 个舱体**（高 ≈2.4）；穹顶数从 1 改**多个小穹顶**；环带从**水平单环**改**多层错位环**；副楼由"平铺"改"环绕塔基" |

**变体分配**：每格 `variant` 由确定性哈希决定（`0/1/2`），Unity 侧按 `(Zone, Era, Variant)` 解析 Prefab。**首批只做 A/B 两型**（`variant=2` 可暂时回落到 A 或 B，后续补齐）。

> ⚠️ **E3 起必须同时提供副楼**：主楼 + 2–3 个缩小副楼，复用主楼 Mesh。**副楼不单独建模**（见 `05` §1.3），由 Unity 侧实例化/缩放置入。

## 5. 首批住宅验收标准（复用 `05` §4，逐项可执行）

| # | 检查项 | 判定 |
|---|---|---|
| 1 | Blender 内结构/比例/材质合规 | 占地 ≤1.0×1.0；高度落在本时代分带；原点在底面中心；材质 ≤2 |
| 2 | 导出后轴向/比例/原点/材质无错 | 新工程导入：不躺倒、Scale=1、落格偏差 = 0 |
| 3 | Unity 可导入并生成 Prefab、正确落格 | 恰好占 1 格、无偏移 |
| 4 | **实际游戏视角下能辨别时代** | 5 时代并排截图，**遮住标签**仍可区分（本方案的核心目标） |
| 5 | 不遮挡相邻、无异常穿插 | 8 邻域满排场景无穿模；遮挡在约定阈值内 |
| 6 | 材质/网格/碰撞体满足性能目标 | 材质 ≤2；无 Mesh Collider；同屏实例达当前帧率目标 |
| 7 | **更换住宅模型不破坏数据/流程/存档** | 同一存档替换前后建筑数/产出/人口一致 |

**批量前置门**：**首批 5 时代 × 2 变体（共 10 个）全部通过后**，才允许批量制作农田/工业/教堂/奇迹（任务书 §4.3）。

## 6. 后续建筑类型的升级方向（规划，不立即执行）

> 原则：**若某类建筑不适合复用住宅的设计逻辑，必须单独设计**（任务书 §4.3）。

| 类型 | 可复用住宅逻辑？ | 升级方向 |
|---|---|---|
| **农田** | 部分 | 农田在游戏里**不建独立建筑**（Web `noBuilding = true`，直接画地表作物）。Unity 侧建议用**低面数地表模块拼装**：E1 零散地块 → E2 规整畦垄 → E3 条田+谷仓 → E4 机械化大片 → E5 垂直农场/发光培养舱（沿用 `FARM_CROP`/`FARM_SOIL` 时代色） |
| **工业** | **否，需单独设计** | 已有 5 型语义（土窑/作坊/工场/锯齿厂房/反应堆）。工业需**更复杂的构件组合**（管道/储罐/烟囱），不能套住宅的"墙+顶"逻辑 |
| **教堂** | **否，需单独设计** | 已有 5 型（巨石阵/柱廊神庙/哥特教堂/新古典穹顶/星际圣殿）。教堂是**信仰经济载体**，体量可与住宅不同、需更强的竖向与装饰性 |
| **时代奇迹** | **否，单独设计** | 5 座（巨石阵/金字塔/大教堂/摩天塔/太空电梯）。每座**独一无二**、体量可超一格、是**时代的地标**，需要单独的 LOD 与阴影策略 |

## 7. 需要在 Blender/Unity 中验证的开放项

| 项 | 为什么需要实测 |
|---|---|
| 高度分带 0.9 / 1.2 / 1.4 / 2.2 / 1.7 | 是否在俯视视角下仍能区分；E4 是否过高遮挡 |
| 受控外挑上限（建议 ≤0.55，硬上限 0.65） | 实机观感是否"偏挤"（Web 待办已提出该风险） |
| 面数 | `05` §1.5 的初始区间必须用首批实测校准 |
| 副楼数量与缩放比 | E5 的 `BUILD_Q=20` 需几个副楼才"可信"而不拥挤 |
| 材质/顶点色方案 | 顶点色（Web 做法）能否在 Unity 显著减少材质球 |
| LOD 需求 | 俯视视角 + 相机拉远程度决定 LOD 是否有收益 |
| 时代可辨识度（第 4 项验收） | **必须用真实截图**判定，不能靠文字描述 |

> **本方案不包含任何已完成的模型**。本沙箱无 Blender，无法建模、导出或验证；以上均为**规格与待验证清单**。
