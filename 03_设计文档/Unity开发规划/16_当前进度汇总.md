## 四、已冻结的关键决策

| 决策 | 内容 |
| --- | --- |
| 引擎版本 | Unity 6 LTS（6000.x） |
| 渲染管线 | URP |
| 业务资源目录 | 沿用 `Assets/_Project/`（不使用 `_Game`） |
| Unity 工程根 | `05_UnityProject/`，保留 Unity 必需的 `Packages/`、`ProjectSettings/` |
| 版本管理 | 启用 Git LFS；`.blend` 大源文件待首批建筑通过 Unity 导入验证后再定 |
| 首发平台 | Windows PC x64 |
| 性能目标 | 1080p；最低 30 FPS，推荐 60 FPS；硬件最低规格待 MVP 实测后冻结 |
| Web 存档迁移 | **仅迁移文明进度**（人口/信仰/神力/星级/奇迹等），不迁移原始地形与建筑格子布局；保留原始 seed 与存档；因缺少地形生成器版本，明确提示 Unity 重生成地形不保证与 Web 一致 |
| 导入器前置 | 开发导入器前先定义人口/奇迹/里程碑 → Unity 运行状态转换规则（见 `15_Web存档迁移规则.md`） |
| MVP 首个交付 | 蛮荒时代（E1）最小可玩闭环优先，不一次性开发全部时代 |
| 分环境并行 | 批准：Unity 环境建工程/asmdef/场景骨架/编译验证；纯逻辑 C# 可在有编译器环境并行，但须统一数据契约与程序集边界 |
