# 02 · Unity 开发任务清单

> 第一阶段交付物 2/9。配套：`01_项目现状与差距分析.md`、`03_Unity开发路线图.md`、`04_Unity技术架构方案.md`。
> 本清单是**任务拆解**，不是排期承诺。任务 ID 唯一、可追踪；验收标准均为**可实际验证**的行为，不以"创建文件/编写代码"本身作为验收。

## 0. 估算假设（适用于全表，请先阅读）

| 项 | 假设 |
|---|---|
| 人力 | **1 名**熟悉 Unity + C# 的开发者，全职工作（8 小时/日） |
| 工时口径 | 表中"人日"= **净开发工时**（含自测），**不含**返工、等待、评审、环境安装 |
| 美术 | **M14（Blender 建模）单独计"建模人日"**，不与程序工时混算 |
| 环境 | 假定目标环境**已有 Unity + Blender**；本沙箱两者均无，故 M1/M14 的实际执行需在具备环境处进行 |
| 依赖 | "前置依赖"仅列**硬依赖**；软依赖以文字说明 |
| 范围 | 仅覆盖 Web Demo **已验证存在**的玩法 + 已文档化的剧情/评分（新增系统） |
| 不含 | 战斗、抽卡、联网、云存档、i18n、商业化（均为【不适用】） |
| 参考基线 | 所有数值以 `01_WebDemo/js/config.js` + `js/formulas.js` 为准，`numeric-design.md` 为规格参照 |

**优先级定义**（沿用任务书）：

- **P0**：项目能运行，核心玩法闭环成立，关键数据与资源结构可靠。
- **P1**：完整时代内容、主要建筑、UI、存档与剧情接入。
- **P2**：高级特效、精细化模型、性能深度优化、非核心体验提升。
